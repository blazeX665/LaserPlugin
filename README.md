# LaserPlugin

Лазерная пушка для Minecraft **Paper 1.21.11** (Java 21).

## Возможности
- Предмет «Лазерная пушка» (ПКМ — выстрел лучом из частиц)
- Урон, дальность, перезарядка, поджиг и цвет настраиваются в `config.yml`

## Команды
| Команда | Описание | Право |
|---|---|---|
| `/laser` | Выдать пушку себе | `laser.give` |
| `/laser give <ник>` | Выдать игроку | `laser.give` |
| `/laser reload` | Перезагрузить конфиг | `laser.give` |

Право `laser.use` (по умолчанию у всех) разрешает стрелять.

## Сборка
```
mvn package
```
Готовый jar: `target/LaserPlugin.jar`. Положить в папку `plugins/` сервера.

Также jar собирается автоматически через GitHub Actions (вкладка Actions → Artifacts).
